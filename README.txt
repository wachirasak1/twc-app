TWC Warehouse — แอปมือถือ (Android / iPhone)
================================================

ในโฟลเดอร์นี้คือ "ตัวแอป" ที่ติดตั้งลงมือถือได้ (Progressive Web App)
แตะไอคอนแล้วเข้าระบบ TWC Warehouse ได้ทันที ข้อมูลทั้งหมดยังอยู่ใน Google Sheets เดิม

ไฟล์
  index.html             หน้าเปิดแอป (Splash / หน้าไม่มีเน็ต / ตั้งค่าครั้งแรก)
  manifest.webmanifest   ชื่อแอป ไอคอน สี และทางลัด (สแกนจ่าย / รับเข้า)
  sw.js                  ทำให้ติดตั้งได้และเปิดไว
  icons/                 ไอคอนแอปทุกขนาด


ขั้นที่ 1  ใส่ลิงก์ระบบ (ทำครั้งเดียว)
------------------------------------------------
เปิด index.html ด้วย Notepad แล้วแก้บรรทัด

    const TWC_WEBAPP_URL = '';

ให้เป็นลิงก์ Web app ของ Apps Script (Deploy → Manage deployments → คัดลอก URL ที่ลงท้าย /exec) เช่น

    const TWC_WEBAPP_URL = 'https://script.google.com/macros/s/AKfycb...../exec';

(ถ้าเว้นว่าง แอปจะถามลิงก์ตอนเปิดครั้งแรกในแต่ละเครื่อง)


ขั้นที่ 2  นำขึ้นเว็บฟรีด้วย GitHub Pages (ประมาณ 5 นาที)
------------------------------------------------
1. สมัคร/เข้าสู่ระบบ https://github.com
2. กด New repository → ตั้งชื่อ เช่น twc-app → เลือก Public → Create repository
3. กด "uploading an existing file" → ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ icons) ไปวาง → Commit changes
4. ไปที่ Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save
5. รอ 1–2 นาที จะได้ลิงก์ เช่น  https://ชื่อบัญชี.github.io/twc-app/

(ใช้ Netlify Drop https://app.netlify.com/drop แทนได้ — ลากโฟลเดอร์นี้ไปวาง ได้ลิงก์ทันที)


ขั้นที่ 3  ใส่ลิงก์แอปในระบบ
------------------------------------------------
เข้าระบบด้วย admin → เมนู ตั้งค่า → ช่อง "ลิงก์แอปมือถือ" → วางลิงก์จากขั้นที่ 2 → บันทึก
ระบบจะสร้าง QR Code สำหรับติดตั้งแอปให้พนักงานสแกน


ขั้นที่ 4  ติดตั้งลงมือถือพนักงาน
------------------------------------------------
Android (Chrome):  สแกน QR → แตะ "ติดตั้ง" (หรือ ⋮ → ติดตั้งแอป) → ไอคอนจะอยู่ในหน้าแอป
iPhone (Safari):   สแกน QR → แตะปุ่มแชร์ ⬆ → "เพิ่มไปยังหน้าจอโฮม" → เพิ่ม
จากนั้นแตะไอคอน TWC Warehouse → เข้าสู่ระบบ (ติ๊ก "จดจำการเข้าสู่ระบบ") หรือกด "สมัครใช้งาน"


(ไม่บังคับ) ทำเป็นไฟล์ APK สำหรับ Android
------------------------------------------------
1. เปิด https://www.pwabuilder.com → วางลิงก์จากขั้นที่ 2 → Start
2. กด Package For Stores → Android → Generate Package → ดาวน์โหลด .zip
3. ในไฟล์ .zip จะมีไฟล์ .apk ส่งให้พนักงานติดตั้ง (ต้องอนุญาต "ติดตั้งแอปจากแหล่งที่ไม่รู้จัก")
   หรือใช้ไฟล์ .aab อัปโหลดขึ้น Google Play Console
เก็บไฟล์ signing key ที่ได้ไว้ให้ดี — ต้องใช้ตอนอัปเดตแอปครั้งถัดไป


การอัปเดต
------------------------------------------------
- แก้ code.gs / index.html ของระบบ แล้ว Deploy → New version (ลิงก์เดิม) แอปบนมือถือได้ของใหม่ทันที ไม่ต้องติดตั้งใหม่
- ถ้าสร้าง Deployment ใหม่ (ลิงก์ /exec เปลี่ยน) ต้องแก้ TWC_WEBAPP_URL แล้วอัปโหลด index.html ขึ้น GitHub อีกครั้ง


ข้อควรรู้
------------------------------------------------
- แอปต้องใช้อินเทอร์เน็ต (ถ้าไม่มีเน็ต จะแสดงหน้าแจ้งพร้อมปุ่มลองใหม่)
- บัญชี Google ส่วนตัว (gmail) อาจมีแถบเล็กด้านบน "This application was created by a Google Apps Script user" เป็นข้อกำหนดของ Google
- ถ้ากล้องแบบสดเปิดไม่ได้ในบางเครื่อง ให้กด "ถ่ายรูปบาร์โค้ดแทน" ในหน้าต่างสแกน หรือใช้เครื่องยิงบาร์โค้ดบลูทูธ
